Accessibility statement.

This site targets WCAG 2.1 Level AA conformance. If you find something that doesn't meet that bar, I want to know about it.

Conformance

Targeting WCAG 2.1 Level AA.

This site is designed, built, and tested against WCAG 2.1 Level AA. Every public page has been evaluated against this standard at the time of publication.

Conformance covers static HTML, CSS, and the small JavaScript file used for navigation. The site contains no third-party embeds beyond a mailto link and a calendar booking link to an external service, which has its own accessibility statement.

Report an issue

If something doesn't work, write me.

The fastest way to report an accessibility issue is to email me directly. Helpful details:

  • The URL of the page where the issue occurred
  • The browser and assistive technology you were using
  • What happened and what you expected to happen

I read every message personally and reply within two business days.

Testing approach

How the site is tested.

Each page is tested with a combination of automated and manual checks:

  • axe DevTools for automated WCAG 2.1 AA evaluation
  • Manual keyboard navigation across every interactive element, with focus order and visible focus verified
  • Mobile viewport testing at 320, 375, 768, and 1280 pixels
  • Color contrast verified at 4.5:1 for body text and 3:1 for large display text
  • Screen reader spot-checks with VoiceOver on macOS and iOS

Pages are re-tested when copy or layout changes meaningfully.

Compatibility

Browsers and assistive technology.

  • Browsers: Chrome, Safari, Firefox, Edge — current and previous major versions on macOS, Windows, iOS, and Android.
  • Screen readers: VoiceOver on macOS and iOS, NVDA on Windows.
  • Magnification: tested at up to 200% browser zoom and at maximum system magnification on iOS and Android.
